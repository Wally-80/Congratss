# CONTRIBUTING

## Local Setup
1. Clone the repository.
2. Run `npm install`.
3. Set up environment variables in `.env.local`.
4. Run `npm run dev`.

## Branching & PR Rules
- Branch from `main` for new features or bug fixes.
- Use descriptive branch names (e.g., `feat-authentication`).
- Ensure all tests pass before submitting a PR.
- Request review from at least one collaborator.
